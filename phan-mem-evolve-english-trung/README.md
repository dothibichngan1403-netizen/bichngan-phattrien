# Phần mềm EVOLVE ENGLISH — bản riêng cho Mr Trung

Bản giao diện phần mềm của app EVOLVE ENGLISH – Giao Tiếp Thích Ứng Mỗi Ngày
(thanh tiêu đề, thanh trình đơn, thanh công cụ, cây thư mục 12 lĩnh vực bên trái,
thanh trạng thái). Một file `index.html` duy nhất, đã nhúng sẵn 2 ảnh trợ lý đồng hành.

Mở bằng Chrome trên điện thoại hoặc máy tính để dùng được giọng đọc và micro.
